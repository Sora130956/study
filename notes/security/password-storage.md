# 密码存储与安全（撞库 / 哈希 / BCrypt）

> **来源:** Mini CRM W2 设计 users 表时的延伸讨论（密码为何不能明文入库）
> **对应计划周次:** 第 2 周 · 设计 User 表（W3 接 Spring Security 时落地 BCrypt）

## 核心理解

设计 `users` 表时确立的安全基线：**密码绝不明文入库，只存单向哈希值**。原因有三层——防数据库泄露后明文暴露、防撞库连锁灾难、连系统自己都不该知道用户原始密码。

正规系统对密码做的是「哈希」而非「加密」：哈希单向不可逆，只能验证不能还原。所以「忘记密码」只能重置（设新密码），不能找回原密码——能找回原密码的网站说明存了明文，是严重安全缺陷。Mini CRM 用 Spring Security 默认的 `BCryptPasswordEncoder`，`users.password VARCHAR(100)` 存的就是 BCrypt 哈希（60 字符）。

## 关键点

### 1. 撞库（Credential Stuffing）

攻击者拿从 A 网站泄露的「账号+密码」，去 B/C/D 网站挨个尝试登录，赌用户多站复用同一密码。

```
1. 某论坛被脱库，泄露 10 万条明文 "邮箱+密码"
2. 攻击者拿这批数据写脚本
3. 去网银/邮箱/电商挨个自动登录
4. 用户若复用密码 → 其他账号沦陷
```

与暴力破解的区别：

| | 暴力破解 | 撞库 |
|---|------|------|
| 手段 | 对一个账号狂试各种组合 | 拿已泄露的真实密码去别处试 |
| 命中率 | 低（靠猜） | 高（用真密码赌复用） |

与密码存储的关系：存明文 → 泄露后用户成了别人撞库的「弹药」；存哈希 → 泄露的是哈希值，无法还原明文，无法拿去撞库。

### 2. 哈希 vs 加密（关键区分）

| | 加密 Encryption | 哈希 Hashing |
|---|------|------|
| 方向 | 双向，能加密能解密还原 | **单向**，只能算过去无法还原 |
| 目的 | 保护数据，之后要还原使用 | 验证一致性，不需还原 |
| 例子 | AES、RSA | BCrypt、SHA-256、MD5 |
| 密钥 | 有，拿密钥能解密 | 无解密一说 |

密码场景要的就是**单向**：系统从不需要解出原密码，只需「下次输入时再哈希一遍比对是否一致」。

### 3. BCrypt 三大特性

BCrypt 是**密码哈希函数**（不是加密算法）。

**① 单向不可逆**
```
"abc123" ──BCrypt──> "$2a$10$N9qo8uLOickgx2ZMRZoMy..."
反向无法还原出 "abc123"
```

**② 自带加盐（salt）—— 防彩虹表**
盐 = 随机字符，混进密码再哈希。效果：两人密码都是 `abc123`，存库的哈希也完全不同。

```
用户A "abc123" + 盐X → 哈希值1
用户B "abc123" + 盐Y → 哈希值2  （与哈希值1 完全不同）
```

让攻击者预算好的「明文↔哈希」对照表（**彩虹表**）失效。盐存在哈希结果里（`$2a$10$` 后那段），验证时取出来用。

**③ 故意"慢"—— 可调计算成本**
```
$2a$10$N9qo8uLOickgx2ZMRZoMy...
     └┬┘ cost=10，计算做 2^10 轮
```
MD5/SHA 设计目标是快（每秒几十亿次），用于密码反而方便黑客暴力破解。BCrypt 故意慢，`cost` 可调（机器变快就调大），让暴力破解每秒只能试几千次，成本不划算。

### 4. 哈希结构与 Spring Security 用法

`$2a$10$....`：`$2a$` 算法版本、`10` cost、其后 22 字符盐 + 31 字符哈希，合计 60 字符。`VARCHAR(100)` 留有余量。

```java
// 注册：存哈希
String hash = passwordEncoder.encode(rawPassword);   // 存进 users.password
// 登录：再哈希比对（不是解密）
boolean ok = passwordEncoder.matches(rawPassword, hash);
```

Spring Security 默认提供 `BCryptPasswordEncoder`，W3 接登录时落地。

## 术语表

| 英文 | 词性 | 释义 |
|------|------|------|
| Credential Stuffing | n. | 撞库，用已泄露账密去别站批量试登录 |
| Brute Force | n. | 暴力破解，对单账号狂试密码组合 |
| Hashing | n. | 哈希，单向不可逆，验证用不还原 |
| Encryption | n. | 加密，双向可还原 |
| BCrypt | n. | 密码哈希函数，含盐 + 可调成本 |
| salt | n. | 盐，随机串，使相同密码哈希结果不同 |
| rainbow table | n. | 彩虹表，预算的明文↔哈希对照表 |
| cost / work factor | n. | 计算成本因子，决定哈希轮数（2^cost） |
| PasswordEncoder | n. | Spring Security 密码编码器接口 |
