# study

Mini CRM 转型计划的学习笔记仓库。

> 配套作品代码在 `mini-crm/` 工程；整体计划在 `docs/superpowers/plans/2026-06-07-mini-crm-transition-plan.md`。

## 目录组织（按主题，不按周）

```
study/
├── notes/
│   ├── java/          # 现代 Java 特性等
│   ├── spring-boot/   # Boot 配置、自动装配等
│   ├── jpa/           # Spring Data JPA、Hibernate
│   ├── security/      # Spring Security、JWT
│   ├── aop/           # 切面、多租户、数据范围
│   ├── transaction/   # 事务管理
│   ├── redis/         # 缓存
│   ├── testing/       # 单元/集成测试、Testcontainers
│   ├── openapi/       # springdoc
│   └── deploy/        # Docker、上线、Nginx
├── templates/
│   └── note-template.md
└── weekly-review.md   # 每周复盘
```

## 笔记工作流

1. 读官方文档时，按 `【URL】【原文1】【备注1】【原文2】【备注2】…` 整理后发给助手
2. 助手据此整理为结构化笔记，存入对应主题目录
3. 笔记结构：核心理解 → 关键点（原文+中文理解+代码）→ 句子解析 → 术语表
